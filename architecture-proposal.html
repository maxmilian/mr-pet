Mr.Pet × PetRisk.AI 雙系統架構提案

子域名獨立部署 · SSO 單點登入 · 去識別化資料隔離 · GCP 多租戶 SaaS

🛒 Mr.Pet 電商 & 飼主端 (C端)

  • • 獨立網域：mrpet.tw
  • • 上架寵物用品、食品、體驗券等商品
  • • 綠界 NewebPay 金流 + 電子發票
  • • PetPoint 紅利點數累積與折抵機制
  • • PWA 行動優先，Next.js + Tailwind

🩺 PetRisk.AI 獸醫端 SaaS (B端)

  • • 子域名獨立：vet.mrpet.tw（未來可拆站）
  • • 多租戶架構：每間診所獨立 Workspace
  • • 醫療影像上傳（X光 / CT / 超音波）
  • • Vertex AI 提供 Second Opinion 輔助診斷
  • • 期刊論文 RAG 知識庫支撐可解釋性

🔒 安全 & 合規設計

  • • SSO 單點登入：LINE / Google / Apple ID
  • • Token ID 去識別化：獸醫看不見其他醫院身分
  • • 資訊隔離：醫療個資 vs 電商資料完全切分
  • • ISO 27001 個資保護合規
  • • 隱私條款 + 免責聲明 + 使用者同意書
